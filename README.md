# 高中英语 AI 训练场

一个**本地运行、零依赖**的高中英语练习工具：填入任意 OpenAI 兼容接口的 API Key，按自定义的**词汇、语法范围、题型、语篇主题**自动生成练习题；支持**作文 AI 批改**、**错题本**与**错题重练**。素材来自公开语料（维基百科语篇、COCA 词频表带中文释义、Tatoeba 例句）。

- 纯前端（原生 ES Modules，无构建步骤）+ 一个 150 行的 Node 本地服务
- 只用 Node 内置模块，`npm install` 都不需要
- API Key 只存在你自己的浏览器里，请求经 `127.0.0.1` 本地服务转发
- **没有 Key 也能用**：内置「演示模式」，离线体验完整流程

---

## 快速开始

需要 **Node.js 18+**（用到内置 `fetch`），无需任何依赖。

**Windows**：双击 `start.bat`（已默认带上本机代理 `127.0.0.1:7897`，按需修改）或在命令行：

```bash
cd english-trainer
set "HTTP_PROXY=http://127.0.0.1:7897"
set "HTTPS_PROXY=http://127.0.0.1:7897"
set "NODE_USE_ENV_PROXY=1"
node server.mjs
```

**macOS / Linux**：

```bash
cd english-trainer
HTTPS_PROXY=http://127.0.0.1:7897 HTTP_PROXY=http://127.0.0.1:7897 NODE_USE_ENV_PROXY=1 node server.mjs
# 或者：npm start
```

然后打开 <http://localhost:5175>。

> 代理怎么填？服务端要出网去抓维基百科 / 词库 / 例句，并转发 AI 请求。直连能通就不必设置代理变量；需要代理时，`NODE_USE_ENV_PROXY=1` 是关键——Node 只认启动时已有的代理环境变量。
> 端口被占用时会直接提示，可用 `PORT=5176 node server.mjs` 换端口。

### 上手步骤

1. 打开「设置」页：从**服务商预设**下拉里选一家（DeepSeek / 通义千问 / Kimi / 智谱 GLM / OpenAI / OpenRouter / 硅基流动 / 本地 Ollama）自动填好 **API Base**；接中转站等自定义接口就直接手填。
2. 填 **API Key**（只存本机浏览器），点 **「拉取可用模型」**——会向 `${API Base}/models` 请求你账号**当前真实可用**的模型列表（不消耗 token，最多缓存 12 小时），点标签就能选模型，不必手打名字。
3. 点「测试连接」确认模型能正常对话。表单里除 Key 以外的选项都是**改完即时保存**。
4. 保持勾选「使用本地代理转发」（推荐）。浏览器直连第三方接口常被 CORS 拦，走本地服务转发更稳。
5. 没有 Key 时勾选「演示模式」（顶部状态胶囊会显示 `演示模式`），用内置示例题体验出题 → 练习 → 判分 → 错题本 → 作文批改的完整流程。

## 功能一览

| 模块 | 说明 |
|---|---|
| **AI 出题** | 词句填空选择、语法单选、词形/拼写、阅读理解、句子翻译；每种 0–10 题；可指定重点词汇、语法考点（12 类）、语篇主题 |
| **联网素材** | Wikipedia 语篇（CC BY-SA）、COCA 20000 词频表含中文释义（mahavivo/english-wordlists）、Tatoeba 例句（CC BY）；统一经本地服务 `/api/fetch` 抓取，失败自动降级不影响出题 |
| **开始练习** | 逐题作答 → 「看提示」（不露答案）→ 交卷判分 → 每题给答案、中文解析与重点词 |
| **判分策略** | 选择题与拼写题**本地判**（免费、即时）；翻译等开放题先按标准化文本比对，不完全一致时进入**自评**（对 1 分 / 部分 0.5 分 / 错 0 分），也可一键「AI 批改开放题」——所有待评定题目**合并成一次请求**批量判定 |
| **写作批改** | 生成作文题（应用文 / 议论文 / 读后续写 / 概要写作）→ AI 按高考评分标准给总分、维度分、逐句修改、润色范文与评语 |
| **错题本** | 答错与部分正确的题自动收录，记录**你的答案**、判定与 AI 点评；可**一键重练**（自动还原成一套试卷）、单条移除、清空 |
| **数据与隐私** | 设置、试卷、作文历史、错题本全部存在本机浏览器 localStorage；服务只监听 `127.0.0.1` |
| **模型选择** | 模型名**不写死**：从 `${API Base}/models` 实时拉取账号可用的模型，点标签即选中，并会提示已下线/改名的旧模型；另附 8 家常用服务商的接口地址预设 |

### 省 token 的设计

多次调用会显著增加费用，因此生成与批改都做了收敛：

- 出题**只调用一次** AI，阅读短文多题共用一篇时只输出一次，前端自动继承
- 判分、提示、解析、错题本**全部本地完成，0 token**
- 提示词使用紧凑单行 JSON 格式，并对解析/提示/点评/修改条数设定字数上限
- 每次调用都限制 `max_tokens`（出题 4000 / 作文批改 2000 / 作文题 500 / 开放题批改 1200）
- 作文正文超过 2000 字符自动截断
- 界面在每次调用后显示**真实消耗的 token 数**（来自上游返回的 `usage`）
- 「拉取可用模型」走的是模型列表接口，**完全不消耗 token**

## 工作原理

```
浏览器（静态页面，ES Modules）
  │  /api/chat     POST，头带 x-api-key / x-api-base  → 转发到任意 OpenAI 兼容接口
  │  /api/models   GET，同样带两个头                   → 转发 GET {API Base}/models
  │  /api/fetch    GET ?url=...                        → 代抓维基百科 / 词库 / 例句
  ▼
server.mjs（Node 内置 http，127.0.0.1:5175，零依赖）
  · 静态托管、CORS 规避、限流 60 次/分钟/IP
  · /api/fetch 只允许公网 http(s)，拒绝内网/本机地址
  · /api/health 供页面探测服务与代理状态
```

## 常见问题

**页面顶部显示「代理✗」或提示未检测到本地服务**
没启动 `node server.mjs`，或端口不是 5175。启动后刷新即可；若你刻意不用本地代理，可在设置里取消「使用本地代理转发」。

**点「测试连接」报 CORS / Failed to fetch**
用的是直连模式，而该接口未开放浏览器跨域。改回「使用本地代理转发」并确保本地服务在运行。

**抓不到网络素材**
`/api/fetch` 需要服务器能出网。国内网络通常要设置 `HTTPS_PROXY`，注意必须是**启动进程前**的环境变量，并配合 `NODE_USE_ENV_PROXY=1`。抓取失败不会阻塞出题，只是题干没有外部语境。

**点「拉取可用模型」时报 401 / 403**
该 Key 无权读取模型列表，或 Key 填错、填了其他服务商的 Key。以网页右上角胶囊显示的模式为准，先点「测试连接」确认能对话；确实拿不到列表时直接手动输入模型名也能用。

**点「拉取可用模型」时报 404**
这个接口没有提供模型列表（部分中转站如此）。手动输入模型名即可，其余功能不受影响。

**拉到的列表里没有我一直在用的模型**
说明该模型确实已下线或改名，页面会直接标出「当前模型不在列表中」提醒你别再选它。换成列表里的新模型即可。

**AI 返回的不是有效 JSON / 空内容**
偶发，尤其在小模型或温度偏高时。解析器已容忍 ```json 代码围栏与多余前后文；仍然失败就重新点一次出题，或换一个更强的模型。

**答案判错了**
客观题本地判分依赖模型给出的标准答案与可接受变体；模型对同义表达可能给不出全部变体，此时翻译题会进入开放题流程（自评或 AI 批量批改），不会白白扣分。

**端口被占用**
换端口：`PORT=5176 node server.mjs`，并用新端口打开页面。
